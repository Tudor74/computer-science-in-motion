# Favicons

One `favicon.ico` per In Motion site (16, 32, 48 and 64 px): a white wave with a tracing dot on the course's accent colour from the hub card (`--accent` in `index.html`); the hub uses the ink colour. Each file is uploaded as `favicon.ico` to the root folder of the site it is named after, where browsers request it automatically, so no page needs to change. `preview.png` shows them all.
